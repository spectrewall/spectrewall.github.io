# Blacklist
{: .no_toc }

Item blacklist management. A blacklisted item mints no graded variants, rolls no grade at craft, and keeps its native rarity border.

1. TOC
{:toc}

### `/mw blacklist add <itemId>`

<p class="cmd-access">masterwork.admin</p>

Add an item id to the grade blacklist.

### `/mw blacklist list`

<p class="cmd-access">masterwork.admin / masterwork.config.view</p>

List every blacklisted item id.

### `/mw blacklist remove <itemId>`

<p class="cmd-access">masterwork.admin</p>

Remove an item id from the blacklist.
