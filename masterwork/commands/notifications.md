# Notifications
{: .no_toc }

Server wide switches, distinct from a player's own `progression notify` opt out. Bare `/mw notifications` prints all four states. Every leaf is admin only, unlike `progression notify`.

1. TOC
{:toc}

### `/mw notifications announce <on|off>`

<p class="cmd-access">masterwork.admin</p>

The global chat broadcast on a Masterwork tier craft.

### `/mw notifications level <on|off>`

<p class="cmd-access">masterwork.admin</p>

Whether the level up toast can fire for anyone.

### `/mw notifications welcome <on|off>`

<p class="cmd-access">masterwork.admin</p>

The one time first join welcome message. Turning it off stops it reaching players who have not yet seen it; it never un-greets anyone who already has.

### `/mw notifications xp <on|off>`

<p class="cmd-access">masterwork.admin</p>

Whether the per craft XP toast can fire for anyone.
